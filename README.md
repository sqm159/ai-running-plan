# AI 中长跑周期训练计划生成器

这是一个静态网页原型，用于根据用户输入的目标项目、当前能力、训练周期、训练条件和进一步需求，生成 800m 到 5000m 的周期性跑步训练计划。

## 功能

- 支持 800m、1500m、3000m、5000m 目标项目
- 根据成绩估算速度、速度耐力、乳酸能力、VO₂max、有氧能力、阈值能力等评分
- 自动判断训练短板
- 生成基础期、强化期、专项期、调整期的周期训练计划
- 支持用户输入进一步需求或近期反馈，动态调整训练强度、负荷和训练内容

## GitHub Pages 发布方式

1. 在 GitHub 新建一个公开仓库，例如 `ai-running-plan`。
2. 上传本文件夹中的所有文件到仓库根目录。
3. 进入仓库的 `Settings`。
4. 打开 `Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. Branch 选择 `main`，目录选择 `/root`。
7. 保存后等待 1-3 分钟，GitHub 会生成公网访问链接。

发布后的网站地址通常是：

`https://你的GitHub用户名.github.io/仓库名/`
