NextLap 隐私政策

本政策适用于 NextLap 网站（含 GitHub Pages）、PWA 与 Android 应用。生效日期：2026 年 8 月 24 日。

开发者可通过 GitHub Issues 联系。

1. 我们收集的信息

  • 账号信息：邮箱，或用于登录的手机号（系统会把它做成内部账号标识，不会把短信验证码存进网站文件）。
  • 运动档案：你填写的昵称、年龄、性别、身高、体重、训练年限、跑量、目标项目和目标成绩等。
  • 训练数据：成绩记录、每日训练日志、能力分析结果、训练计划，以及你导入的运动文件（如 FIT）。
  • 技术日志：登录服务可能记录发短信的时间，用于防止频繁发送验证码。

2. 我们如何使用这些信息

仅用于创建账户、完成登录验证、保存和同步你的训练数据，以及生成能力分析与训练计划。我们不会出售你的个人数据，也不会用这些数据投放广告。

3. 数据处理方

  • Supabase：账户与训练数据的存储和访问控制。
  • 阿里云号码认证（短信认证）：向中国大陆手机号发送登录验证码。
  • Cloudflare：登录中转服务，密钥不放在网站前端。

4. 保存期限

数据会保存到你删除账户为止。删除账户后，账号及关联训练数据会被清除，且不能恢复。

5. 你的权利

你可以在应用内查看和修改运动档案。如需删除全部数据，请登录后打开「运动档案」，使用「删除账户」。你也可以通过上述 GitHub Issues 提出访问或删除请求。

6. 未成年人

本应用面向有自主训练需求的跑者，不面向 14 周岁以下儿童。若我们发现误收集了儿童个人信息，会尽快删除。

7. 政策更新

若本政策有重大更新，我们会在本页面公布。继续使用 NextLap 即表示你了解更新后的政策。
